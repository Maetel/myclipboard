# 마이메모 클립보드 Windows 사용자 시나리오

## 첫 사용과 계정

1. 사용자는 `memos.my`에서 자유롭게 가입하고 웹 메모 화면에 들어갑니다.
2. Windows 앱에서 같은 아이디와 비밀번호로 로그인합니다. 앱 전용 세션만 Windows 사용자 보안 저장소에 남고 비밀번호는 저장하지 않습니다.
3. 웹의 **기기 간 클립보드**에 현재 기기가 나타납니다. 사용자는 웹에서 분실한 기기를 로그아웃할 수 있습니다.
4. 일반 계정은 메모 파일과 클립보드 기록을 합쳐 50MiB까지 저장합니다. `stan`은 사용량은 표시하되 상한을 적용하지 않습니다.
5. 예전 `admin.memos.my` 버전에서 업데이트한 사용자는 이관 안내를 보고 마이메모 계정으로 한 번 다시 로그인합니다. 기존 서버 기록은 이미 같은 `stan` 계정으로 옮겨져 웹에서 보입니다.

## 복사와 다른 기기에서 사용

- 텍스트나 링크를 복사하면 현재 기기의 로컬 기록에 즉시 들어가고 온라인이면 마이메모에 전송됩니다. 웹과 같은 계정의 다른 기기에서 같은 내용과 출처 기기를 확인할 수 있어야 합니다.
- 네트워크가 끊기면 전송 대기열에 암호화해 보관하고, 다음 복사·수동 동기화·기록 창 열기 때 같은 event ID로 재전송합니다. 재시도 때문에 항목이 중복되면 안 됩니다.
- 이미지와 일반 파일 하나는 10MiB 이하만 받습니다. 다른 기기에서 실제로 선택하기 전에는 일반 파일 원본을 읽거나 전송하지 않습니다. 폴더와 여러 파일은 경로를 훑지 않고 무시합니다.
- 원격 파일을 고르면 원본 기기가 온라인일 때만 임시 전송을 시작합니다. 크기와 SHA-256이 모두 맞아야 적용하며 실패하면 기존 클립보드와 원본 파일을 바꾸지 않습니다.

## 기록 창 열기·선택·취소

1. 사용자가 붙여넣을 앱을 앞에 둔 채 `Ctrl+Shift+V`를 누르면 기록 창이 열리고 검색창에 초점이 갑니다.
2. 방향키는 선택만 옮깁니다. Enter 또는 항목 클릭만 선택한 내용을 클립보드에 적용하고, 기록 창을 열기 직전의 앱으로 붙여넣기를 시도합니다.
3. 사용자가 마음을 바꿔 Escape를 누르거나 기록 창 밖을 클릭하면 아무 항목도 적용하지 않고 창이 닫힙니다.
4. 내부 항목을 클릭하는 순간의 focus 이동은 외부 클릭으로 오인하지 않습니다. 붙여넣기는 정확히 한 번만 실행되어야 합니다.
5. 검색·파일 받기·붙여넣기가 실패하면 창을 유지하고 오류를 짧게 표시하며 검색/키보드 초점을 복원합니다.
6. 새 기록이 없거나 변경 없는 동기화 응답에서는 목록 DOM, 선택, 검색어, scroll 위치를 다시 만들지 않습니다.

## 로그아웃·용량 초과·복구

- 앱에서 로그아웃하면 이 기기의 세션, 로컬 기록, 전송 대기열과 암호화 키를 지웁니다. 다른 기기와 서버 기록은 유지합니다.
- 웹에서 기기를 로그아웃하면 그 기기는 다음 요청에서 로그인 화면으로 돌아가고 로컬 비밀 데이터를 정리합니다.
- 50MiB를 넘는 새 영구 기록은 저장하지 않고 기존 기록은 그대로 둡니다. 사용자에게 웹에서 파일이나 기록을 정리하라고 안내합니다.
- 용량 초과나 일시적인 전송 실패가 나도 해당 항목과 파일 원본은 암호화된 로컬 대기열에 남고, 정리·재연결 뒤 같은 event ID로 다시 전송합니다.
- 앱 재시작과 Windows 재로그인 뒤에도 인스턴스는 하나만 실행되어야 하며 보이는 console 창이 없어야 합니다.
- 유휴 상태에서는 Clipboard를 열거나 서버를 polling하지 않습니다. 복사 알림, 기록 창 열기, 수동 동기화처럼 사용자가 만든 사건에서만 작업합니다.

## Windows 완료 기준

- 신규 가입 → 앱 로그인 → 텍스트 복사 → 웹 확인 → 두 번째 Windows 세션에서 붙여넣기까지 실제 계정으로 통과합니다.
- 기록 창을 10회 열어 Escape/외부 클릭/내부 클릭을 번갈아 수행해 취소 시 clipboard 불변, 선택 시 한 번만 적용됨을 확인합니다.
- offline 3개 복사 후 reconnect에서 순서와 중복 없음, 앱 재시작 후 대기열 복구를 확인합니다.
- 일반 계정 50MiB 경계의 허용/거부와 `stan` 50MiB 초과 허용, 사용량 표시를 확인합니다.
- 30분 유휴 동안 network 요청, 암호화 상태 write, Clipboard open이 0이고 visible console/중복 process가 0인지 계측합니다.
